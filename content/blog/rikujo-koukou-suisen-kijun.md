東京の私立高校や都立高校の陸上競技の推薦の基準は、100mや1500mのタイムより「都道府県大会で8位以内に入賞」「都大会に出場」のような大会の成績で書かれていることがほとんどで、推薦の話は中3の6月から8月の大会や高校の体験練習会のころから進みます。全国レベルの記録の目安には全日本中学校陸上競技選手権大会（全中）の参加標準記録があり、2026年度は男子100mが11秒05、女子100mが12秒40でした。

![陸上競技場のトラックに置かれたストップウォッチとスパイク](/images/blog/rikujo-koukou-suisen-kijun-track.jpg)

## 推薦の基準の書かれ方

陸上競技を含む高校のスポーツ推薦では、多くの学校が実績の条件を大会での順位や出場で書いていて、ここで挙げた学校の要項に、タイムの基準を書いたものはありません。たとえば早稲田実業高等部は、次の表のように、陸上競技を含む個人的スポーツの推薦の資格を大会の順位と出場で決めています。

| 学校 | 運動部の推薦の実績の条件 | 評定の条件・選考の方法 |
|---|---|---|
| 早稲田実業（2026年度入試） | 都道府県大会で8位以内に入賞、または全国・関東大会等に出場（陸上はトラック種目と駅伝のみ） | 中3の全必修教科の評定合計34以上、2以下なし |
| 都立足立新田（2026年度入試） | 個人種目で都大会に出場した者、またはそれと同等の能力をもっている者 | 個人面接500点・実技検査300点で選抜 |
| 都立若葉総合（2027年度入試） | 陸上競技の技術・能力に優れ、中学校または地域の陸上競技部に所属して活躍した者 | 調査書（内申）500点・個人面接200点・実技検査300点 |

![陸上の高校推薦の基準が大会の順位や出場で書かれている例と、子どもの記録の比べ方](/images/blog/rikujo-koukou-suisen-kijun-kijun.png)

都立のスポーツ推薦は正式には文化・スポーツ等特別推薦と呼ばれ、中学校長の推薦を受けて出願し、多くの学校で調査書、面接、実技検査の合計点で合否が決まります。

### 子どもの記録と条件の比べ方

子どもの記録が推薦の条件に近いかどうかは、子どもの通信陸上の記録を、前年の都道府県大会で8位に入った選手の記録と比べると見当がつきます。全日本中学校通信陸上競技大会（通信陸上）は、共通の要項で各都道府県が6月ごろに開く大会で、出場したすべての中学生の記録が日本陸上競技連盟のサイトに載ります。前年の都道府県大会の結果は、都道府県の陸上競技協会や中学校体育連盟のサイトで公開されていることがあります。

### 駅伝と跳躍・投擲の扱い

長距離の選手には駅伝の成績を実績に含める学校があり、短距離や跳躍、投擲の選手は個人種目の大会の成績が中心になります。早稲田実業は陸上競技で出願できる種目を「トラック種目および駅伝」とし、駅伝のようにチームで出る大会では、8位以内に入賞したチームの正選手であることを条件にしています。早稲田実業の推薦には跳躍や投擲の実績では出願できないので、これらの選手は受けたい学校の募集要項で種目の欄を先に読んでおく必要があります。

## 100mや1500mのタイムの目安は？

全中は、決められた期間の大会で参加標準記録を突破することが出場の条件の一つになっている全国大会で、推薦の基準に「全国大会に出場」と書く学校では、2026年度の第53回全中の標準記録が目安になります。

| 種目 | 男子 | 女子 |
|---|---|---|
| 100m | 11秒05 | 12秒40 |
| 200m | 22秒50 | 25秒80 |
| 400m | 51秒00 | 全中の種目になし |
| 800m | 1分59秒00 | 2分15秒50 |
| 1500m | 4分06秒50 | 4分38秒00 |
| 3000m | 8分55秒50 | 全中の種目になし |
| ハードル | 110mH 14秒60 | 100mH 14秒50 |
| 走幅跳 | 6m60 | 5m40 |
| 砲丸投 | 13m40 | 12m50 |

手動計時の記録と追い風参考記録は標準記録の対象にならず、走高跳、棒高跳、四種競技の標準記録は通信陸上の要項に載っています。2026年度は多くの種目で前年より標準記録が引き上げられていて、標準記録は毎年見直されるため、子どもが中3になる年度の数字は、その年の通信陸上の要項で確かめておく必要があります。

## 中学生の陸上選手に高校から声がかかるのはいつ？

陸上競技で高校から推薦の話が出る時期は、中3の6月から8月の個人種目の大会と、同じ時期に開かれる高校の陸上部の体験練習会のころが中心です。推薦の話は、子どもが高校の練習会に参加したり、中学校の先生を通して相談したりするなかで進みます。表には2027年4月入学向けの日程を挙げ、2028年4月入学向けの日程は各大会と各校が改めて発表します。

| 時期 | 大会・手続き |
|---|---|
| 6月（日程は都道府県ごとに異なる） | 全日本中学校通信陸上競技大会 |
| 7月〜8月 | 高校の陸上部の体験練習会（日大豊山は7月20日と8月17日） |
| 8月6日・7日 | 関東中学校陸上競技大会（山梨県） |
| 8月20日〜23日 | 全日本中学校陸上競技選手権大会（山口県） |
| 10月23日〜25日 | U16陸上競技大会（三重県） |
| 12月中旬 | 私立高校の入試相談・資格相談 |
| 2027年1月22日前後 | 私立高校の推薦入試 |
| 2027年1月26日・27日 | 都立高校の推薦の検査 |

![陸上の中3の大会と推薦の日程（2027年4月入学向けの例）](/images/blog/rikujo-koukou-suisen-kijun-calendar.png)

日大豊山の陸上部の体験練習会は、保護者のほか、中学校の陸上競技部の顧問やクラブチームの監督にもあてて案内されています。練習会の案内は顧問やクラブの監督を通して届くことがあるので、推薦を考えている場合は、夏の大会の前に顧問やクラブの監督に伝えておくと安心です。

### 入試相談と資格相談

東京の私立高校では、12月に中学校の先生が高校に2学期までの成績を伝える入試相談があり、推薦では大会の実績が出願資格に当たるかを高校に確かめてもらう資格相談を設ける学校もあります。たとえば早稲田実業の2026年度入試の活動実績資格相談は、11月22日から12月7日に予約を受け付け、12月15日から17日に行われました。予約は推薦入試の2か月ほど前に始まることもあるので、夏の大会の結果が出たら、受けたい学校の募集要項で予約の時期を確かめておけば出遅れずに済みます。

中3の秋にも10月のU16陸上競技大会などがありますが、推薦の出願に使える大会の期間は学校ごとに違います。秋の記録が使えるかどうかは、出願する学校の募集要項で確かめるか、中学校の先生に聞いておく必要があります。

## 記録が伸びなかったときの都立のスポーツ推薦

都立のスポーツ推薦には、大会の記録とは別に基礎的な運動能力を実技検査で見る学校があり、足立新田の推薦の基準も「都大会に出場した者」のほかに「それと同等の能力をもっている者」を含めています。足立新田の2026年度入試の実技検査は、立ち五段跳び（その場から5歩続けて跳んだ距離を測る種目）と、60m走か20mシャトルランのどちらかでした。都立のスポーツ推薦の配点の読み方と日程は、次の記事にまとめています。

## 大会と定期テストが重なる時期

陸上の大会は中3の6月から10月まで続き、1学期の期末テストや2学期の中間テストの時期と重なります。私立の推薦には陸上の実績とは別に評定の条件があるので、大会の日程と定期テストの日程を先に1枚に書き出しておくと、大会が近い週とテストが近い週で勉強の量を変える計画が立てやすくなります。たとえばテストの2週間前に大会がある月は、大会の前の週から、1日の量は少なくてもテスト範囲の見直しを始めておけば、勉強がテストの直前に偏らずに済みます。中3の2学期の成績の決まり方は、次の記事にまとめています。

## よくある質問

### クラブで競技している子は誰に推薦の相談をすればいいですか

推薦の出願にはどの学校でも中学校の先生を通した手続きがあるので、クラブの監督に加えて、中学校の担任にもクラブで競技していることと推薦を考えていることを伝えておきます。体験練習会の案内がクラブの監督にあてて届く学校もあるため、受けたい学校の候補は監督にも早めに伝えておくと安心です。

### 推薦で不合格だったら一般入試は受けられますか

推薦で不合格だった場合も、そのあとの一般入試に出願でき、都立の一般入試の学力検査は2027年2月21日です。推薦の発表から一般入試の出願までの期間が短いため、一般入試で受ける学校は推薦に出願する時点で決めておくと安心です。
